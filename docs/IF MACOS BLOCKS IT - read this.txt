IF macOS BLOCKS THE PLUGIN
==========================

Short version: the "Allow / Open Anyway" button in System Settings does NOT
work for audio plug-ins. Don't look for it. Use the Terminal command below
instead — it is the actual fix.

WHY THERE IS NO BUTTON
----------------------
System Settings > Privacy & Security only offers "Open Anyway" for an APP that
you double-clicked. A VST3 or Audio Unit is not an app — it is a bundle that
Ableton loads — so macOS blocks it silently and never shows you a button to
click. On recent macOS the old right-click > Open trick is gone too.

The real problem is a hidden "quarantine" flag that macOS attaches to anything
that arrives by download, AirDrop, Messages or email. Removing that flag is all
that is needed, and it takes one command.

THE FIX
-------
1. Install the plugin first (drag it into the folder), THEN do this. Doing it in
   the other order does nothing, because the flag travels with the file.

2. Open Terminal (Cmd+Space, type "Terminal", Enter).

3. Paste this ENTIRE line and press Enter:

for p in ~/Library/Audio/Plug-Ins/VST3/"Amp Sim.vst3" ~/Library/Audio/Plug-Ins/Components/"Amp Sim.component"; do [ -e "$p" ] || continue; xattr -dr com.apple.quarantine "$p" 2>/dev/null; codesign --force --deep --sign - "$p" >/dev/null 2>&1; echo "fixed: $p"; done; killall -9 AudioComponentRegistrar 2>/dev/null; echo "done"

   It should print "fixed: ..." for each plugin it found, then "done".

4. Quit Ableton completely, reopen it, and rescan:
   Live > Settings > Plug-Ins > Rescan.

IF IT PRINTED ONLY "done" AND NO "fixed:" LINES
-----------------------------------------------
Then the plugin isn't where the command looked. Two common reasons:

  a) It was installed to the SYSTEM folder (/Library/...) instead of the user
     one (~/Library/...). For that, use this version instead — it will ask for
     your password:

sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/"Amp Sim.vst3" /Library/Audio/Plug-Ins/Components/"Amp Sim.component"; sudo codesign --force --deep --sign - /Library/Audio/Plug-Ins/VST3/"Amp Sim.vst3"; killall -9 AudioComponentRegistrar 2>/dev/null; echo done

  b) It is still sitting in Downloads and was never copied. Check the folder:
     in Finder press Cmd+Shift+G and paste  ~/Library/Audio/Plug-Ins/VST3

TO CHECK WHETHER IT WORKED
--------------------------
Paste this; it should say "quarantine gone":

xattr -r -p com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Amp Sim.vst3" >/dev/null 2>&1 && echo "STILL QUARANTINED" || echo "quarantine gone"

A NOTE ON WHY THIS IS NEEDED AT ALL
-----------------------------------
This plugin isn't signed with a paid Apple Developer certificate ($99/year), so
macOS treats it as untrusted software from the internet. Everything above is
just telling your own Mac that you trust this particular file. If it ever gets
properly signed and notarised, none of this will be necessary.

SIDESTEP: if you copy the plugin from a USB stick rather than downloading it,
macOS usually does not attach the quarantine flag in the first place, and it
will just work.
