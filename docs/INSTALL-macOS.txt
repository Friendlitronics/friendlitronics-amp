AMP SIM 0.8.0 — macOS (Apple Silicon + Intel, macOS 11 or newer)
=================================================================

A guitar / bass / acoustic amp sim, pedalboard AND colour box for Ableton.

  * AMP tab: 4 guitar amps, an acoustic piezo-DI amp, 4 bass amps, and a
    Line / Colour path for bus and master processing
  * PEDALS tab: 8 pedals on a chain strip you can DRAG TO REORDER. The amp
    itself is a tile in that chain: pedals left of it feed the amp input,
    pedals right of it run after the cab like an effects loop.
  * 23 factory rigs + 10 factory pedalboards (shoegaze, indie, funk, blues,
    ambient, grunge), and SAVE for your own
  * TAPE / FLUTTER / CRUSH / SR / NOISE / NARROW for lofi and tape colour

There are two copies of the same plugin in this folder:
  Amp Sim.vst3        <- VST3 (recommended for Ableton)
  Amp Sim.component   <- Audio Unit (optional; also works in Logic/GarageBand)

1. COPY THE PLUGIN
   In Finder, press Cmd+Shift+G, paste the path below, press Enter, and drag the
   file into that folder (create the folder if it doesn't exist):

     Amp Sim.vst3       ->  ~/Library/Audio/Plug-Ins/VST3
     Amp Sim.component  ->  ~/Library/Audio/Plug-Ins/Components

   >>> If macOS blocks it and the "Allow" button in System Settings does
   >>> nothing (or never appears), that is expected for plug-ins. See
   >>> "IF MACOS BLOCKS IT - read this.txt" in this folder.

2. LET macOS RUN IT (one time)
   The plugin isn't signed with a paid Apple developer certificate, so macOS
   blocks it after downloading ("damaged" or "can't be verified"). Open Terminal
   (Cmd+Space, type Terminal), paste this whole line, and press Enter:

     xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Amp Sim.vst3" ~/Library/Audio/Plug-Ins/Components/"Amp Sim.component" 2>/dev/null; killall -9 AudioComponentRegistrar 2>/dev/null; echo done

   (It's fine if you only installed one of the two files.)

3. SCAN IN ABLETON
   Live > Settings (Live 11: Preferences) > Plug-Ins tab:
     - turn on "Use VST3 Plug-in System Folders" (and/or "Use Audio Units v2")
     - click "Rescan"
   Then in the browser: Plug-Ins > Elegancia > Amp Sim. Drop it on a track.

PRESETS
  The menu is split into FACTORY RIGS, FACTORY PEDALBOARDS, and your own saved
  ones. SAVE asks whether to store Everything, Amp only, or Pedalboard only —
  so you can drop any board onto any amp. An amp preset never moves your
  pedals, and a board preset never touches your amp.
  They are files in ~/Library/Application Support/Amp Sim/Presets.

NOTES
  - Drag tiles in the chain strip to reorder, including the AMP tile. Click a
    tile to toggle that pedal.
  - WAH's Pedal knob and WHAMMY's Pitch knob are meant to be automated in Live.
    Wah's AUTO makes it an envelope filter instead.
  - WHAMMY tracks single notes; chords warble (it is a delay-line shifter).
  - For bus/master colour, use the "Master:" presets, or the Line amp with cab
    and mic set to "None (line out)".
  - With FLUTTER above 0, keep MIX at 100%.
